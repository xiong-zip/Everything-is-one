    工作原理

    遵循 Agent 的经典编排范式：理解意图 → 拆解规划 → 工具调用 → 汇总输出。

    01 ◎

    理解意图

    接收一句复合指令，用 LLM 解析真实意图与隐含约束：城市、日期、文案风格、输出对象。

    analyze("查厦门天气，再写朋友圈文案")
    02 ▦

    拆解规划

    把大目标拆成有依赖顺序的子任务，生成可执行的 Plan：查天气 → 提炼要点 → 生成文案。

    plan() → [3 个子任务]
    03 ⚙

    工具调用

    按需调用已注册的工具：天气查询、股票接口、LLM 生成等，形成「思考 → 行动 → 观察」的 ReAct 循环。

    tool.weather.query({city})
    04 ❖

    汇总输出

    收集所有子任务的结果，统一整理成最终答案，一步到位交付给用户。

    aggregate() → 成品
    03

    技术亮点

    基于 Java 生态的 Agent 编排技术栈，简历亮点直接拉满。

    Agent 编排框架

    LangChain4j / Spring AI

    统一管理 LLM 调用、ChatMemory 与工具注册，用 Java 优雅地编排多步骤 Agent 任务。

    推理模式

    ReAct 循环

    模型按「思考 → 行动 → 观察」自主决策下一步：该查天气就调工具，该写文案就调用生成。

    能力扩展

    Function Calling

    把业务能力（查天气、查股价、生成文案）注册为可被模型调用的函数，即插即用。

    实时体验

    流式输出

    SSE / WebFlux 将任务过程与日志流式返回，前端实时渲染执行进度，观感接近生产环境。
